# Версия для телефона

Сайт работает в браузере Android и iPhone. Отдельный APK не требуется.

1. Подключите компьютер и телефон к одной доверенной Wi-Fi-сети.
2. Если сервер запущен через `Start.cmd`, остановите его с помощью Ctrl+C.
3. Запустите `Network.cmd` и оставьте окно открытым.
4. Откройте на телефоне адрес, показанный после `Phone URL`.
5. Введите отдельный пароль приложения из `APP_PASSWORD` в `.env`.

`Network.cmd` сам определяет локальный IPv4 и разрешает этот конкретный origin
на время работы. Файл `.env` не изменяется. Пароль для сетевого доступа обязателен;
при `COOKIE_SECURE=true` используйте настроенный HTTPS-сервер.

Внизу экрана доступны Дом, Мониторинг, История, Правила и Ещё.
В меню Ещё находятся аналитика, устройства, подключение и настройки.
История на телефоне показана карточками. Таблицу технических Data Points можно
прокручивать внутри её блока. Поля форм имеют размер, подходящий для экранной
клавиатуры, а кнопки увеличены для нажатия пальцем.

Если адрес не открывается, проверьте Wi-Fi и работу сервера. При запросе
брандмауэра Windows разрешайте Python только для доверенной домашней сети.
Гостевая Wi-Fi-сеть может запрещать связь устройств между собой. Не отключайте
брандмауэр целиком. Скрипт не изменяет брандмауэр и не открывает порты роутера.

На iPhone можно добавить открытую страницу через «Поделиться → На экран Домой»;
на Android — через меню браузера «Добавить на главный экран». Это ярлык на сайт.
Для обновления данных нужен интернет и работающий сервер; автономная работа
без сервера не предусмотрена. При смене сети адрес компьютера может измениться.

Для доступа через мобильный интернет нужен постоянно работающий сервер с
доменом и HTTPS. Настройка описана в `CONNECTION_GUIDE.md`.
